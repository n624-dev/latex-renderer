## Открытие и сохранение PDF {#pdf-を開く-保存する}

- **Веб-приложение.** Выберите документ в [истории](/app/history/) и откройте `result.pdf` в списке файлов на странице результатов. Если заказаны PDF и SVG, PDF можно скачать сразу после его подготовки.
- **CLI.** Скачайте результат с помощью указанного `<jobId>`. Добавьте `--pdf-only`, чтобы получить PDF, не дожидаясь SVG. Если нужно сохранить файлы другого документа, выберите другую папку с помощью `--output`.

```sh
n624-latex jobs download <jobId> --pdf-only --output .render
```

## Получение изображений страниц {#ページ画像を取得する}

Для изображений целых страниц используйте предварительный просмотр в PNG. Изначально создаётся только страница 1. Остальные формируются по запросу. Если изображение готовится, немного подождите или откройте страницу снова. Готовый PDF можно скачать уже сейчас.

- **Веб-приложение.** На странице результатов выберите изображение нужной страницы.
- **CLI.** Следующая команда скачивает PNG для страниц 2 и 5. Имена файлов имеют вид `.render/previews/page-2.png`.

```sh
n624-latex jobs download <jobId> --preview-page 2 5 --output .render
```

## Сохранение формул и TikZ в SVG {#数式と-tikz-を-svg-で保存する}

Внешние математические выражения и рисунки TikZ верхнего уровня можно извлечь в виде отдельных векторных изображений.

- **Веб-приложение.** Перед преобразованием откройте **Назначение и параметры вывода** и выберите **Также экспортировать формулы и TikZ в SVG**. По окончании извлечения скачайте SVG со страницы результатов.
- **CLI.** Запустите преобразование с `--svg`. SVG сохраняются в `.render/svg/objects/`. Соответствие между строками исходного `.tex` и координатами в PDF указано в `.render/svg/manifest.json`.

```sh
n624-latex render . --svg
```

## Если PDF готов, но извлечение SVG завершилось ошибкой {#pdf-はあるが-svg-が失敗した場合}

**Частичный успех** означает, что PDF готов, а ошибка произошла только при извлечении SVG. Сохраните PDF и повторите извлечение без его перекомпиляции.

- **Веб-приложение.** Нажмите **Повторить только SVG** на странице результатов.
- **CLI.** Выполните команду.

```sh
n624-latex jobs retry-svg <jobId> --output .render
```

**Условия и число попыток**
- Доступно **до 8 попыток**, включая первую, пока исходные файлы и готовый PDF доступны, а среда TeX на сервере остаётся прежней. Повторные попытки не продлевают срок хранения.
- Если ошибка повторяется, посмотрите диагностику на странице результатов или в `.render/svg/errors.json`.
- При сообщении `SVG_RUNTIME_CHANGED` или отсутствии кнопки для старого задания [создайте новое преобразование из исходного документа или сохранённой ревизии](/ru/docs/web/#以前の文書や結果を開く).

См. также [Скачивание и повторные попытки через HTTP API](/ru/docs/api/#pdfの先行公開とsvgの再試行) и [Спецификация обработки выходных данных](https://github.com/n624-dev/latex-renderer/blob/main/docs/independent-output-stages.md).
