## Изменение руководства {#本文を編集する}

- **Сообщить об ошибке.** Если руководство расходится с интерфейсом или командами, создайте обращение в [GitHub Issues](https://github.com/n624-dev/latex-renderer/issues/new/choose), указав страницу и предлагаемое исправление.
- **Предложить изменение.** Отредактируйте нужный файл в [исходниках публичных руководств в Markdown (`docs/public/`)](https://github.com/n624-dev/latex-renderer/tree/main/docs/public) и откройте pull request.

## Локальная проверка {#ローカル検証}

После редактирования выполните команды и убедитесь, что сборка и проверки ссылок и заголовков HTTP прошли успешно.

```bash
pnpm install --frozen-lockfile
pnpm --filter @latex-renderer/web... build
pnpm --filter @latex-renderer/public-web build
pnpm check
```

При сборке `public-web` выполняется пробный запуск Wrangler и запускается локальная среда Workers для проверки типовых страниц, поискового индекса, ошибок 404, перенаправлений и заголовков HTTP.

## Совместимость {#互換性}

- Сохраняйте публичные пути и якоря заголовков (фрагменты `#...`, образованные из текста). При изменении заголовка проверьте ссылки с других страниц.
- При изменении параметров CLI или примеров HTTP-запросов проверяйте их соответствие реализации и определениям OpenAPI.
