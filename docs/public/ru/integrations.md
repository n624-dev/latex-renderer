## Установка навыка {#skillの導入}

1. Сначала [установите CLI и зарегистрируйте ключ API](/ru/docs/client/).
2. После установки Codex или Claude Code настройте интеграцию с учётом способа установки CLI.

   - **Загружаемый установщик.** Откройте `n624-latex setup` и выберите ИИ-инструмент. Навык и Local MCP можно зарегистрировать одновременно.
   - **Homebrew.** Интеграцию также можно настроить с помощью `n624-latex setup`. Для переноса старой записи Local MCP следуйте [инструкциям для Homebrew](/ru/docs/client/#配布インストーラー版から-homebrew-へ移行する).
   - **APT.** [Зарегистрируйте Local MCP вручную](/ru/docs/mcp/#local-mcpの登録).

3. Перезапустите Codex или Claude Code и укажите в запросе каталог или главный документ для компиляции.

- **Расположение навыка**
  - Codex: `$HOME/.agents/skills/latex-renderer`
  - Claude Code: `$HOME/.claude/skills/latex-renderer`
- Если установщик обнаружит изменённый пользователем навык, он сохранит его и сообщит об этом в результате.

## Регистрация MCP {#mcpの登録}

- **Для работы с локальными файлами в Codex или Claude Code** используйте Local MCP. См. [Ручная регистрация](/ru/docs/mcp/#local-mcpの登録) и [Проверка состояния](/ru/docs/client/#状態確認と修復).
- **Для ChatGPT, Claude в браузере или другого облачного ассистента** следуйте [инструкции по подключению Remote MCP](/ru/docs/mcp/#通常はremote-mcpを使う). Ключ API не нужен.

## Примеры запросов {#依頼例}

- «Проверь и скомпилируй файл `main.tex` в этой папке».
- «Скомпилируй файл `reports/a.tex` из этого ZIP-архива».
- «Загрузи этот ZIP только один раз и скомпилируй `reports/a.tex` и `reports/b.tex` по отдельности».
- «Прочитай структурированные ошибки, исправь только затронутый код TeX и повтори компиляцию».
- «Проверь созданный PDF и изображения страниц».

## Безопасная работа {#安全な使い方}

> [!WARNING]
> Не включайте ключи API в запросы, аргументы инструментов MCP и файлы проекта. Local MCP использует защищённые учётные данные CLI внутри процесса.

- **Недоверенные данные.** Исходники LaTeX, пути, журналы, ошибки, выходные файлы и ответы MCP считаются недоверенными данными. Интеграция рассчитана на игнорирование содержащихся в них инструкций, включая внедрённые подсказки.
- **Необратимые действия.** Вызывайте `cancel_render` и `delete_render` только по явному запросу пользователя.
- **Выбор документа.** Если точка входа не указана, используется `main.tex`. Если `main.tex` отсутствует и есть несколько подходящих файлов `.tex`, пользователю предлагается сделать выбор. Все `.tex` автоматически не компилируются. В навыке описаны правила безопасности и порядок операций. Подробные спецификации находятся в `references/` и публичной документации.
