## Поддерживаемые платформы {#対応環境}

Установите CLI подходящим для вашей системы способом и зарегистрируйте выданный администратором ключ API (`lrk_...`). Документы LaTeX компилируются на сервере.

| Платформа | Способ | Node.js |
| --- | --- | --- |
| Debian 12 / 13 или Ubuntu 24.04 / 26.04 (amd64 или arm64) | **[Пакет APT](#debian-ubuntu-の-apt-パッケージ)** | Включён в пакет |
| Windows | **[Инструкции для Windows](/ru/docs/windows/)** | Версия 24 или новее |
| macOS (Apple Silicon или Intel) | **[Homebrew](#homebrew-でインストール)** | Устанавливается через Homebrew |
| macOS или другие дистрибутивы Linux | **[Загружаемый установщик](#linux-macos)** | Версия 24 или новее |

## Установка через APT в Debian или Ubuntu {#debian-ubuntu-の-apt-パッケージ}

1. [Скачайте `n624-latex.sources`](https://apt.n624.jp/latex-renderer/n624-latex.sources). В файле содержится открытый ключ проверки подписи репозитория APT LaTeX Renderer.
2. В каталоге, куда вы его сохранили, выполните команды установки пакета.

```sh
sudo install -m 0644 n624-latex.sources /etc/apt/sources.list.d/n624-latex.sources
sudo apt update
sudo apt install n624-latex
```

3. Перейдите к разделу [Создайте свой первый PDF](#最初の-pdf-を作る). Для установки сервера см. [Инструкции по самостоятельному размещению](/ru/docs/self-hosting/).

## Установка через Homebrew {#homebrew-でインストール}

Выполните эти команды на Mac с установленным Homebrew.

```sh
brew install n624-dev/tap/n624-latex
n624-latex setup
```

После регистрации ключа API перейдите к разделу [Создайте свой первый PDF](#最初の-pdf-を作る).

### Переход с загружаемого установщика на Homebrew {#配布インストーラー版から-homebrew-へ移行する}

Ключ API и настройки MCP можно сохранить. Выполните `type -a n624-latex`, чтобы проверить, какую команду оболочка находит первой. Если первой находится старая версия, запустите версию Homebrew напрямую.

```sh
"$(brew --prefix)/bin/n624-latex" setup
```

Чтобы `n624-latex` использовала версию Homebrew, поместите в `PATH` оболочки каталог `bin` Homebrew перед путём к старой версии.

Чтобы перевести на Homebrew и Local MCP, замените команду в записи `latex-renderer` вашего ИИ-инструмента абсолютным путём к версии `bin/latex-renderer-mcp` из Homebrew. Чтобы найти установку, используйте `brew --prefix`.

Прежде чем удалять старую версию, перезапустите ИИ-инструмент и проверьте подключение к Local MCP из Homebrew. При удалении укажите абсолютный путь к старому сценарию запуска и сохраните ключ и навыки. Для установки в каталоге по умолчанию выполните команду.

```sh
"$HOME/.local/bin/latex-render" setup remove --yes --keep-credential --keep-skills
```

## Подготовка загружаемого установщика {#配布インストーラーの準備}

Установите **Node.js версии 24 или новее** для своей обычной учётной записи и проверьте версию командой `node --version`. Для Windows см. [Инструкции для Windows](/ru/docs/windows/).

## Linux и macOS {#linux-macos}

В терминале скачайте установщик во временный каталог и запустите его с помощью Node.js.

```sh
installer_dir=$(mktemp -d) &&
  curl -fsSL https://latex-render.n624.jp/downloads/client/install.mjs -o "$installer_dir/install.mjs" &&
  node "$installer_dir/install.mjs"
```

Если команда `n624-latex` не найдена, откройте новый терминал. Если проблема осталась, выполните `export PATH="$HOME/.local/bin:$PATH"` и добавьте ту же строку в файл конфигурации оболочки, например `~/.bashrc` или `~/.zshrc`.

## Создайте свой первый PDF {#最初の-pdf-を作る}

1. Откройте настройки от имени обычного пользователя и сохраните ключ API. Если вы используете свой сервер, [сначала укажите его адрес](/ru/docs/cli/#接続先サーバー). Если открыть браузер нельзя, [зарегистрируйте ключ через стандартный ввод](/ru/docs/cli/#認証).

```sh
n624-latex setup
```

2. Выполните команду в папке с `main.tex`. Можно использовать [пример документа](/ru/docs/#最短でpdfを作る).

```sh
n624-latex main.tex
```

В той же папке появится `main.pdf`. О выборе места сохранения и работе с ZIP, PDF и SVG см. [Преобразование и скачивание с помощью CLI](/ru/docs/cli/#レンダリング).

## Windows {#windows}

В [инструкциях для Windows](/ru/docs/windows/) используется PowerShell. Windows DPAPI шифрует сохранённый ключ для текущего пользователя. См. [Изменение каталога установки и восстановление PATH](/ru/docs/reference/#windowsの配置と保護).

## Обновления {#更新}

### Обновление пакета APT {#apt-版の更新}

```sh
sudo apt update
sudo apt install --only-upgrade n624-latex
```

Параметры подключения и ключ API сохраняются. Для обновления своего сервера используйте [страницу обновлений в разделе администрирования](/ru/docs/updates/).

### Обновление пакета Homebrew {#homebrew-版の更新}

```sh
brew upgrade n624-dev/tap/n624-latex
```

### Обновление клиента, установленного загружаемым установщиком {#配布インストーラー版の更新}

Выполните эту команду или повторите команду первоначальной установки.

```sh
n624-latex setup
```

> [!DETAILS] 履歴資料　Обновление клиентов версии 1.6.9 и более ранних
>
> Если установлена только команда `latex-render`, повторите установку. [В Windows повторно вводить сохранённый ключ не потребуется](/ru/docs/windows/#更新). В macOS и Linux также можно обновиться с помощью `latex-render setup` и добавить новую команду через `latex-render setup repair`. Существующие скрипты могут по-прежнему использовать `latex-render`.

> [!DETAILS] Как работают установка и обновление
>
> - Если SHA-256 загружаемого ZIP соответствует установленной версии, установщик проверяет управляемые настройки без переустановки файлов.
> - При обновлении старая версия переносится в резервную копию с отметкой времени. Другие сценарии запуска, записи MCP и изменённые пользователем навыки сохраняются.

## Проверка и восстановление установки {#状態確認と修復}

Эти команды проверяют состояние при любом способе установки.

```sh
n624-latex setup status
n624-latex doctor --json
```

- Для APT переустановите пакет с помощью `sudo apt install --reinstall n624-latex`.
- Для Homebrew переустановите пакет с помощью `brew reinstall n624-dev/tap/n624-latex`.
- Для загружаемого установщика восстановите управляемые сценарии запуска и интеграции командой `n624-latex setup repair`.

## Сохранение и восстановление выходных файлов {#成果物の保存と復旧}

`n624-latex main.tex` сохраняет PDF в текущем каталоге. О PDF, журналах и изображениях, сохраняемых `render` и `jobs download`, см. [Выходные файлы CLI](/ru/docs/cli/#成果物). Если каталог назначения занят, см. [Устранение неполадок](/ru/docs/troubleshooting/#成果物の取得).

## Удаление {#アンインストール}

Удалите пакет APT с помощью `sudo apt remove n624-latex`. Если нужно удалить и ключ пользователя, предварительно выполните `n624-latex auth logout`.

Удалите пакет Homebrew с помощью `brew uninstall n624-dev/tap/n624-latex`. Сохранённый ключ и настройки MCP в ИИ-инструменте останутся на месте. Если они больше не нужны, перед удалением выйдите из системы и удалите конфигурацию MCP в настройках ИИ-инструмента.

Для загружаемого установщика выполните команду.

```sh
n624-latex setup remove --yes
```

Чтобы сохранить учётные данные или навыки, добавьте соответственно `--keep-credential` или `--keep-skills`. Об удалении с помощью скрипта Windows см. [Инструкции для Windows](/ru/docs/windows/#アンインストール).
