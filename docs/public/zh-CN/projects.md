## 项目目录结构 {#構成}

- **单文件文档。** 在 Web 应用中直接上传 `.tex`，或在 CLI 中运行 `n624-latex main.tex`。
- **包含图片、参考文献或多个源文件的文档。** 保留相对路径，将所有文件打包为**一个 ZIP**。CLI 也支持直接指定目录。
- **创建 ZIP。** 选择项目目录中的 `main.tex`、`images/` 等内容进行压缩。如果把外层目录也打包了，转换时请将入口设为 `project/main.tex` 这样的相对路径。

```text
project/
├─ main.tex
├─ references.bib
├─ images/
│  └─ figure.png
└─ styles/
   └─ local.sty
```

**入口文件和相对路径**
默认入口是项目根目录下的 `main.tex`。即使选择子目录中的 `.tex` 文件（例如 `docs/main.tex`）作为入口，**编译工作目录仍然是项目根目录**。例如，要从 `docs/main.tex` 引入同目录下的 `body.tex`，应写作 `\input{docs/body.tex}`。如果写作 `\input{body.tex}`，编译器会在项目根目录下查找 `body.tex`。

## 最简日文示例 {#日本語の最小例}

默认引擎为 **LuaLaTeX**。将以下日文文档以 UTF-8 编码保存为 `main.tex` 即可试用。

```latex
\documentclass{ltjsarticle}
\begin{document}
日本語とEnglishを含む文書です。
\end{document}
```

[渲染环境](/app/environment/)可以搜索可用宏包和字体。这份清单在部署时从实际的渲染器容器生成，与 Remote MCP 搜索使用同一数据源。如果缺少宏包，请将 `compile.log` 中的相关消息告知服务器管理员。

## 已保存的项目和修订版本 {#保存projectと改訂}

在 Web 应用（`/app/`）中转换的文档会保存到项目中。

- **自动保存修订版本。** 当同一项目的内容、主文档、引擎和输出格式构成新的组合时，系统会创建新版本。已有版本仍保留在项目历史中。
- **转换以前的版本。** 点击**重新转换**，使用已保存的文档和引擎再次运行。此处选择其他输出格式，只会向同一版本的转换记录添加新结果。
- **跨工具共享和删除。** 同一用户可在 Web、CLI、HTTP API 和 MCP 中访问相同的项目和版本。删除项目会将其从列表中隐藏，已有输入数据和输出文件按各自的保留期限清理。需要立即彻底删除时，请联系管理员。有效版本引用的输入数据也计入用户存储配额。参见[项目共享和保留规则](/zh-CN/docs/reference/#保存プロジェクトの共有-保持)。

### 在浏览器中编辑 {#ブラウザーで編集する}

打开已保存的项目，选择**编辑 TeX**。修改会自动保存到草稿。暂停输入后开始编译，成功时更新 PDF。预览编译失败时，仍可查看上次成功显示的 PDF 及对应的草稿版本。

新项目会打开空白的 `main.tex`。正文为空时，也可以选择模板。若要基于以前的版本继续编辑，请选择**基于此版本编辑**。若已有草稿，系统会在替换前请你确认。

如需手动编译，请关闭**自动编译**并点击**编译**。选择**保存版本的输出设置**后，点击**保存版本**，即可保留当前草稿和输出设置。需要 SVG 时，打开已保存的版本并选择**重新转换**。
编辑时可在编辑器中查看编译进度和预览。

## 上传时排除的文件 {#送信から除外されるもの}

- **自动排除。** CLI 自动排除 `.git`、`.render` 和 LaTeX 生成的辅助文件（如 `.aux`），并拒绝符号链接。
- **不支持的文件。** 将 `node_modules` 等不需要的目录移出项目。上传目录时，若发现不支持的扩展名，CLI 会显示路径并停止。若希望将 `README.md` 等文件留在项目中但不上传，请在项目根目录的 `.latexrenderignore` 中写入 `README.md`。服务器会按相同的扩展名规则验证 ZIP。
- **支持的扩展名**（不区分大小写）
  `.tex`, `.sty`, `.cls`, `.bib`, `.bst`, `.csv`, `.dat`, `.txt`, `.png`, `.jpg`, `.jpeg`, `.pdf`
  `.bst` 是 BibTeX 参考文献样式文件，也可放在子目录中。如果自定义样式文件的扩展名未在列表中，请联系管理员，避免直接修改扩展名。

## 限制 {#制限}

- **文件数量。** 最多 500 个文件。
- **默认大小限制。** 上传 ZIP 为 20 MiB，解压后总计 100 MiB，单文件 20 MiB。
- **入口文件。** 输入包中 `.tex` 文件的相对路径，默认为根目录的 `main.tex`。
- **安全限制。** 禁用 shell escape（包括 `\write18`）、外部命令执行和外部网络通信。
- **资源限制。** 处理时间、每用户存储量及输出保留期均受管理员设置的上限约束。
