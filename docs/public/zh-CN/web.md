## 在浏览器中生成 PDF {#ブラウザでpdfへ変換}

1. 打开 [Web 应用](/app/)，按管理员提供的方式登录。
2. 选择文件，或将文件拖放到页面上。
   - 如果文档只有一个文件，直接选择 `.tex`。
   - 如果文档含图片、参考文献或多个 `.tex` 文件（例如通过 `\input` 引入），将所有引用的文件按原有目录结构打包成一个 `.zip`。参见[支持的文件与 ZIP 目录结构](/zh-CN/docs/projects/)。
   - 如果单独选择多个 `.tex` 文件，系统会分别转换每个文档。
3. 如果 ZIP 内有多个 `.tex` 文件，且页面提示选择转换目标，请选择主文档（入口文件）。
4. 点击**转换为 PDF**。完成后，结果页面会显示 PDF 和页面预览。

要使用 LuaLaTeX 以外的引擎，请在**保存位置与输出选项**中选择**引擎**。[渲染环境](/app/environment/)会列出可用引擎，以及 PDF、SVG 和 SVG 定位的验证情况。使用 pLaTeX 或 upLaTeX 需要服务器安装日语集合。

## 在浏览器中编辑文档 {#ブラウザーで文書を編集する}

1. 从[项目](/app/projects/)打开文档，点击**编辑 TeX**。新项目包含一个空的 `main.tex`，也可以从模板开始。
2. 编辑时会自动保存草稿。通过**添加附件**添加图片或参考文献。
3. 开启**自动编译**后，暂停输入时会更新 PDF。要手动更新，请点击**编译**。
4. 点击**保存版本**可将当前输入保存到历史记录。在历史记录中选择**基于此版本编辑**，即可从该版本继续编辑。如果已有草稿，系统会在替换前请你确认。

在**管理文件**中添加文件或附件。在**设置**中选择引擎、自动编译和显示语言，也可以保存修订版本。PDF 窗格中的 **⋯** 提供缩放和 PNG 选项。

编译失败时，草稿和上次成功生成的 PDF 仍会保留。点击带文件名和行号的错误即可跳转到对应行。在手机上可切换**代码**、**PDF**和**错误**。如果 PDF 显示较慢，可以使用**PNG（轻量预览）**。

临时预览仅在编辑器中显示。如需保留 PDF，请点击**保存 PDF**下载。

编辑器使用 UTF-8 编码。对于 Shift_JIS 或 EUC-JP 文件，请先在文本编辑器中按原编码打开，确认显示正常后，将副本保存为 UTF-8。以相同文件名添加该副本，系统会提示是否替换原文件。

## 将公式和 TikZ 图形导出为 SVG {#数式や-tikz-を-svg-で取得する}

1. 转换前，打开**保存位置与输出选项**，勾选**同时将公式和 TikZ 导出为 SVG**。
2. PDF 生成后即可下载。
3. 如果结果显示**部分成功**，表示 PDF 已生成，但 SVG 提取失败。请先保存 PDF，然后按需点击**仅重试 SVG**。

系统起初只生成第 1 页的 PNG 预览，其他页面在打开时生成。等待预览期间仍可下载已生成的 PDF。参见[获取 PDF、PNG 和 SVG](/zh-CN/docs/outputs/)。

## 打开以往的文档和结果 {#以前の文書や結果を開く}

- **[历史记录](/app/history/)**显示转换进度和输出文件。关闭浏览器后仍可重新打开同一结果页面。
- **[项目](/app/projects/)**列出已保存的文档和修订版本。要使用以前的输入重新转换，请打开对应版本，点击**重新转换**。
- **[渲染环境](/app/environment/)**可用于搜索服务器上安装的 LaTeX 宏包和字体。

## 哪些信息可以公开访问 {#公開される情報}

- **需要登录的页面。** 登录 Web 应用（`/app/`）后，可以在历史记录或结果页面查看自己的文档和转换结果。管理页面（`/admin/`）仅对管理员和所有者开放。参见[账号与文档安全](/zh-CN/docs/security/)。
- **无需登录的页面。** 如果无法登录，请查看[服务状态](/status/)或[故障排查指南](/zh-CN/docs/troubleshooting/)。在[下载页面](/downloads/)获取 CLI，在[公开 API](/zh-CN/docs/api/) 中查看集成规范。
