## 확인 순서 {#確認する順序}

1. **[서비스 상태](/status/) 확인.** 서비스 전체의 장애나 유지보수가 진행 중인지 확인합니다.
2. **기존 작업 확인.** 이미 변환을 시작했다면 웹 앱의 **기록**에서 같은 작업을 열거나 CLI에서 `n624-latex jobs get <jobId>`를 실행합니다.
3. **진단과 로그 확인.** 웹 결과 화면의 진단을 열거나, CLI에서 `.render/errors.json`과 상세 로그 `.render/compile.log`를 확인합니다.

## 자주 생기는 문제 {#代表的な問題}

### 설치와 로그인 {#インストール-ログイン}

- **`n624-latex` 또는 `latex-render`를 찾을 수 없음**
  새 터미널이나 PowerShell 창을 엽니다. 해결되지 않으면 Linux와 macOS에서는 [PATH 설정](/ko/docs/client/#linux-macos)을, Windows에서는 [설치 안내](/ko/docs/windows/#インストール)를 확인합니다.
- **웹 앱에 로그인할 수 없음**
  등록된 계정과 관리자가 안내한 로그인 방식(암호, OIDC 또는 Cloudflare Access)을 사용하고 있는지 확인합니다. ChatGPT나 Claude에서 연결이 중단되면 [Remote MCP 연결 확인](/ko/docs/mcp/#chatgptなどの接続を確認する)을 참고하세요.
- **CLI에서 `401` 또는 `403` 반환**
  `n624-latex auth status`로 키 등록 상태를 확인합니다. 키가 유효하고 `render:create` 및 `render:read:own` 권한이 있는지 관리자에게 확인하고, 필요하면 [키를 다시 등록](/ko/docs/cli/#認証)하세요. 자체 호스팅 환경에서는 [서버 URL(`LATEX_RENDER_BASE_URL`)](/ko/docs/cli/#接続先サーバー)도 확인합니다.

### 업로드와 변환 {#アップロード-変換}

- **ZIP에서 본문을 찾을 수 없음**
  기본 진입점은 루트의 `main.tex`입니다. 부모 폴더까지 압축했는지 확인하거나 본문의 상대 경로를 지정하세요. [ZIP 구성 방법](/ko/docs/projects/#構成)을 참고하세요.
- **파일 크기 또는 확장자 거부**
  불필요한 생성 파일과 지원하지 않는 파일을 빼거나 `.latexrenderignore`를 설정한 뒤 [지원 파일 및 제한](/ko/docs/projects/#制限)을 확인하세요.
- **변환이 대기 중이거나 도중에 연결이 끊김**
  서버에서는 여전히 처리 중일 수 있습니다. 새 작업을 만들기 전에 기존 결과 페이지나 작업 ID를 다시 열어 보세요.
- **패키지 또는 글꼴을 찾을 수 없거나 시간 초과**
  [렌더링 환경](/app/environment/)에서 사용 가능한 이름을 검색합니다. 시간 초과라면 로그가 멈춘 위치 근처에 복잡한 매크로, 큰 이미지, TikZ 그림이 있는지 확인합니다.

### 결과 파일 받기 {#成果物の取得}

- **PDF는 있지만 SVG가 없음**
  **부분 성공**이면 PDF를 먼저 저장한 뒤 **SVG만 재시도**를 선택합니다. [SVG 추출 실패 시 조치](/ko/docs/outputs/#pdf-はあるが-svg-が失敗した場合)를 참고하세요.
- **PNG 미리 보기가 계속 준비 중임**
  잠시 기다리거나 같은 페이지를 다시 엽니다. 확정된 PDF는 바로 받을 수 있습니다.
- **대상 경로가 사용 중이거나 `OUTPUT_BUSY` 발생**
  출력 PDF를 연 뷰어를 닫거나 같은 폴더에 쓰고 있는 다른 프로세스가 끝날 때까지 기다린 뒤 다시 내려받습니다.
- **기한 만료 또는 저장 공간 부족**
  만료된 결과는 저장된 버전이나 로컬 파일로 다시 변환합니다. 개인 용량이 가득 찼으면 불필요한 완료 작업을 삭제하고, 서버 디스크가 가득 찼으면 관리자에게 알립니다.

## 문의 {#問い合わせ}

- **서버 관리자에게 문의.** 발생 시각, 중단된 작업, 오류 코드 및 알고 있다면 작업 ID(`job_...`)를 전달합니다.
- **GitHub 공개 오류 보고.** 비밀 정보와 개인 문서를 제거한 최소 재현 절차를 첨부하세요. **API 키, 쿠키, 원본 문서, PDF 및 편집하지 않은 전체 로그를 공개하지 마세요.**
