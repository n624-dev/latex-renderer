- API 키가 유출되면 즉시 서버 관리자에게 폐기와 재발급을 요청하세요.
- 소프트웨어 취약점은 [GitHub 비공개 취약점 신고 양식](https://github.com/n624-dev/latex-renderer/security/advisories/new)으로 제보하세요. 공개 이슈로 게시하지 마세요.

## 자격 증명 {#資格情報}

- API 키를 명령줄 인수(`ps` 등에서 확인 가능), URL, Git 저장소, 로그 또는 AI 프롬프트에 포함하지 마세요.
- 로컬 저장에는 운영체제의 보호 기능을 사용합니다. Windows에서는 DPAPI, Linux와 macOS에서는 소유자만 읽을 수 있는 모드 `0600` 파일을 사용합니다.
- 브라우저 암호, OIDC 클라이언트 시크릿, 세션 쿠키와 CLI/API용 키(`lrk_`, `lra_`)는 각 용도에 맞게 사용합니다.

## 프로젝트 {#プロジェクト}

업로드한 모든 LaTeX 소스와 첨부 파일은 신뢰할 수 없는 입력으로 처리합니다. 심볼릭 링크, 셸 이스케이프, 외부 명령 실행, 컨테이너 외부 네트워크 통신은 비활성화됩니다. 샌드박스, 시간 제한 및 파일 제한을 준수하세요.

## 공개 영역과 관리 영역 {#公開領域と管理領域}

공개 문서 및 다운로드, 인증된 웹 페이지(`/app/`, `/admin/`), Renderer API는 동일한 정규 HTTPS 출처에서 경로로 구분합니다.

- **네트워크 경계.** Cloudflare 프로필은 Tunnel과 Workers, standalone 프로필은 TLS 리버스 프록시만 진입점으로 사용합니다. 모든 애플리케이션 서비스는 루프백에 바인딩하며 Internal API, SQLite, 관리자 소켓은 외부에 공개하지 않습니다. 인증 영역은 검색 엔진 색인에서도 제외합니다.
- **브라우저 인증과 세션 보호.** 외부 IdP는 `provider + issuer + subject`가 정확히 일치하는 경우에만 같은 신원으로 식별하며 이메일이나 표시 이름으로 계정을 자동 연결하지 않습니다. 서버는 세션을 즉시 폐기할 수 있습니다. 상태 변경 요청은 `Origin`의 정확한 일치 및 세션별 CSRF 토큰을 요구합니다. 암호는 `scrypt`와 root 소유의 비밀값(pepper)으로 보호합니다. 공개 배포에서는 프록시의 연결 수 및 요청 속도 제한과 호스팅 측 DDoS 방어도 적용하세요.
- **Remote MCP.** `/mcp`, OAuth 토큰 엔드포인트 및 검색 메타데이터에는 공개 접근이 가능합니다. 도구 실행에는 대상(audience)과 권한 범위(scope)가 고정된 단기 Bearer 토큰이 필요합니다. 승인 화면은 `/app/`와 같은 브라우저 세션을 사용해 유효한 기존 사용자에게 명시적으로 연결합니다.
  - 표준 도구 응답(`content`)에는 작업 진행에 필요한 소유자 범위 ID, 상태, 커서, 제한된 진단만 포함됩니다. 사용자 제공 경로와 진단 문구는 제어 문자를 제거하고 길이와 수를 제한한 뒤 신뢰할 수 없는 데이터로 반환합니다.
  - 표준 `content`와 진단 로그에는 OAuth 토큰, API 키, 티켓, 원시 base64, 소스 전문, 전체 로그, 스택 추적, Access subject 및 서버 내부 경로를 포함하지 않습니다. 전체 PDF와 로그는 소유자 권한을 재검사하는 리소스 읽기로만 받을 수 있습니다.

## 로컬 설정 웹 화면 {#local-setup-web-ui}

`n624-latex setup --gui`(이전 버전은 `latex-render setup --gui`)는 로컬 기기의 `127.0.0.1`에 있는 임의 포트에서만 수신합니다.

- CLI가 여는 URL 조각(`#...`)에 일회용 부트스트랩 토큰이 포함됩니다. 브라우저는 이를 즉시 기록에서 지우고 단기 세션으로 교환합니다.
- 모든 작업 API는 정확히 일치하는 `Origin`, Bearer 세션, 별도의 CSRF 토큰을 요구합니다. CORS를 비활성화하고 Host 및 루프백 연결 출처를 검증하며 엄격한 CSP, `frame-ancestors 'none'`, `no-store`를 적용합니다.
- 입력한 API 키는 저장 처리에만 전달하며 상태, 진단, 예제 변환 응답에는 포함하지 않습니다. 30분 동안 활동이 없거나 시작 후 2시간이 지나면 자동 종료합니다.
