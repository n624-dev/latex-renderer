## 브라우저에서 PDF 만들기 {#ブラウザでpdfへ変換}

1. [웹 앱](/app/)을 열고 관리자가 안내한 방법으로 로그인합니다.
2. 파일을 선택하거나 화면에 끌어 놓습니다.
   - 파일 하나로 완성되는 문서는 `.tex` 파일을 그대로 선택합니다.
   - 이미지, 참고문헌 또는 여러 `.tex` 파일(`\input` 등으로 포함)이 있는 문서는 참조하는 파일까지 하나의 `.zip`으로 묶습니다. [지원 파일과 ZIP 구성](/ko/docs/projects/)을 참고하세요.
   - 여러 `.tex` 파일을 개별적으로 선택하면 각각 별도 문서로 변환합니다.
3. ZIP에 여러 `.tex` 파일이 있어 변환 대상을 묻는 경우, 본문이 들어 있는 파일을 진입점으로 선택합니다.
4. **PDF로 변환**을 누릅니다. 변환이 끝나면 결과 화면에 PDF와 페이지 미리 보기가 나타납니다.

LuaLaTeX 이외의 엔진을 사용하려면 **저장 위치 및 출력 옵션**의 **엔진**에서 선택합니다. 사용 가능한 엔진과 PDF, SVG, SVG 배치 검증 여부는 [렌더링 환경](/app/environment/)에서 확인할 수 있습니다. pLaTeX와 upLaTeX를 사용하려면 서버에 일본어 컬렉션이 있어야 합니다.

## 브라우저에서 문서 편집하기 {#ブラウザーで文書を編集する}

1. [프로젝트](/app/projects/)에서 문서를 열고 **TeX 편집**을 누릅니다. 새 프로젝트는 비어 있는 `main.tex`에서 시작하며 템플릿도 선택할 수 있습니다.
2. 파일을 편집하면 초안이 자동으로 저장됩니다. 이미지나 참고문헌은 **파일 첨부**로 등록합니다.
3. **자동 컴파일**을 켜 두면 입력을 멈출 때 PDF가 갱신됩니다. 바로 갱신하려면 **컴파일**을 누릅니다.
4. 현재 입력을 기록에 남기려면 **버전 저장**을 누릅니다. 기록에서 **이 버전에서 편집**을 선택하면 해당 버전으로 편집을 시작합니다. 작업 중인 초안이 있으면 교체 전에 확인을 요청합니다.

파일을 추가하거나 첨부하려면 **파일 관리**를 엽니다. 엔진, 자동 컴파일, 표시 언어, 버전 저장은 **설정**에서 이용할 수 있습니다. PDF 창의 **⋯**에서 확대 배율과 PNG 표시를 선택할 수 있습니다.

컴파일이 실패해도 초안과 마지막으로 성공한 PDF는 유지됩니다. 파일명과 줄 번호가 있는 오류를 선택하면 해당 줄로 이동합니다. 스마트폰에서는 **코드**, **PDF**, **오류** 사이를 전환할 수 있습니다. PDF 표시가 느리면 **PNG(가벼운 미리 보기)**를 선택하세요.

임시 미리 보기는 편집기에서만 확인할 수 있습니다. 나중에 사용할 PDF는 **PDF 저장**을 눌러 내려받으세요.

편집기는 UTF-8 텍스트를 사용합니다. Shift_JIS 또는 EUC-JP 파일은 텍스트 편집기에서 원래 인코딩으로 연 뒤 내용이 제대로 보이는지 확인하고 UTF-8 사본을 저장하세요. 같은 이름으로 사본을 첨부하면 교체 여부를 묻습니다.

## 수식과 TikZ 그림을 SVG로 받기 {#数式や-tikz-を-svg-で取得する}

1. 변환 전 **저장 위치 및 출력 옵션**을 열고 **수식과 TikZ도 SVG로 출력**을 선택합니다.
2. PDF는 완성되는 즉시 내려받을 수 있습니다.
3. PDF가 완성되고 SVG만 실패하면 **부분 성공**으로 표시됩니다. PDF를 먼저 저장한 뒤 필요하면 **SVG만 재시도**를 누릅니다.

PNG 미리 보기는 처음에 첫 페이지만 생성하며, 다른 페이지를 열면 그 페이지를 추가로 생성합니다. 미리 보기를 준비하는 동안에도 완성된 PDF를 받을 수 있습니다. [PDF, PNG, SVG 받기](/ko/docs/outputs/)를 참고하세요.

## 공개되는 정보 {#公開される情報}

- **로그인이 필요한 페이지.** 웹 앱(`/app/`)에 로그인하면 기록과 결과 페이지에서 자신의 문서와 변환 결과를 확인할 수 있습니다. 관리 화면(`/admin/`)은 관리자와 소유자만 이용할 수 있습니다. [계정과 문서 보안](/ko/docs/security/)을 참고하세요.
- **공개 페이지.** 로그인할 수 없으면 [서비스 상태](/status/)나 [문제 해결 안내](/ko/docs/troubleshooting/)를 확인하세요. CLI는 [다운로드](/downloads/)에서, 시스템 연동 규격은 [공개 API](/ko/docs/api/)에서 확인할 수 있습니다.
