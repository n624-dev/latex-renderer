## 構成

- **1 ファイルだけの文書**：Web アプリに `.tex` をそのままアップロードできます。CLI では `n624-latex main.tex` で直接変換できます。
- **画像・参考文献・分割ファイルを含む文書**：相対パスを保ったまま **1 つの ZIP** にまとめます（CLI ではフォルダをそのまま指定できます）。
- **ZIP を作るときの注意**：親フォルダごと圧縮するのではなく、フォルダの中にある `main.tex` や `images/` などを選んで圧縮してください（親フォルダごと ZIP にした場合は、変換時に `project/main.tex` のような相対パスをエントリポイントに指定します）。

```text
project/
├─ main.tex
├─ references.bib
├─ images/
│  └─ figure.png
└─ styles/
   └─ local.sty
```

**エントリポイントと相対パスの基準**：
既定の本文（エントリポイント）はプロジェクト直下の `main.tex` です。サブフォルダ内の `.tex`（例：`docs/main.tex`）をエントリポイントに指定した場合でも、**コンパイル時の作業ディレクトリは常にプロジェクトのルート**になります。たとえば `docs/main.tex` から同じフォルダの `body.tex` を読み込む場合は、ルート基準で `\input{docs/body.tex}` と記述してください（`\input{body.tex}` と書くとルート直下の `body.tex` を探します）。

## 日本語の最小例

レンダラーは **LuaLaTeX** を使用します。日本語を含む文書は、次の内容を UTF-8 の `main.tex` として保存して試せます。

```latex
\documentclass{ltjsarticle}
\begin{document}
日本語とEnglishを含む文書です。
\end{document}
```

利用可能なパッケージとフォントは、[レンダリング環境](/app/environment/)の画面から検索できます（デプロイ時に実際の Renderer コンテナから生成される一覧で、Remote MCP の環境検索と共通です）。不足するパッケージ等があった場合は、`compile.log` のメッセージをサーバー管理者へ伝えてください。

## 保存Projectと改訂

Web アプリ（`/app/`）で変換した文書はプロジェクトに保存されます。

- **改訂の自動記録**：同じ保存先でファイル内容やエントリポイントを変更すると新しい「改訂（リビジョン）」として追加され、以前の改訂もそのまま残ります。過去の改訂を開いて**もう一度変換**を押せば、再アップロードなしで変換できます。
- **出力形式の変更**：改訂ごとに PDF / PDF＋SVG を選べます（「初回の設定」はその改訂を最初に保存したときの設定です）。出力形式だけを変えて変換しても新しい改訂は増えず、その改訂の変換履歴に記録されます（「この改訂の履歴をさらに表示」から過去の結果も開けます）。
- **ツール間の共有と削除の扱い**：保存プロジェクトと改訂は、同じユーザーの Web・CLI・HTTP API・MCP で共通です。プロジェクトの削除は一覧から記録を消す操作であり、既存の入力データや成果物はそれぞれの保存期限に従って整理されます（即時完全削除が必要な場合は管理者へ相談してください。また、有効な改訂が参照している入力データもユーザーの保存容量に算入されます。詳細：[保存プロジェクトの共有・保持](/docs/reference/#保存プロジェクトの共有-保持)）。

## 送信から除外されるもの

- **自動除外されるもの**：`.git`、`.render`、および LaTeX が生成した補助ファイル（`.aux` 等）は CLI が自動で除外します。シンボリックリンクは受け付けません。
- **未対応ファイルの扱い**：`node_modules` などの不要なフォルダはプロジェクト外へ移してください。フォルダ指定で送信する際、未対応の拡張子を持つファイルが含まれていると CLI はそのパスを表示して停止します（勝手に除外して送信することはありません）。`README.md` などをプロジェクト内に残したまま除外したい場合は、プロジェクト直下の `.latexrenderignore` に `README.md` と記載してください。送信された ZIP はサーバー側でも同じ拡張子ルールで検証されます。
- **対応する拡張子**（大文字・小文字は区別しません）：
  `.tex`, `.sty`, `.cls`, `.bib`, `.bst`, `.csv`, `.dat`, `.txt`, `.png`, `.jpg`, `.jpeg`, `.pdf`
  （`.bst` は BibTeX の参考文献スタイルファイルで、サブフォルダ内にも配置できます。独自のスタイルファイル等がこの一覧にない場合は、無理に拡張子を書き換えず管理者へ相談してください）。

## 制限

- **ファイル数**：最大 500 ファイル
- **サイズ上限（既定値）**：送信 ZIP 20 MiB、展開後合計 100 MiB、1 ファイルあたり 20 MiB
- **エントリポイント**：Source 内の相対 `.tex` パス（省略時はルート直下の `main.tex`）
- **セキュリティ制限**：シェルエスケープ（`\write18` 等）および外部コマンド実行・外部通信はすべて無効
- **リソース上限**：処理時間、ユーザーごとの保存容量、成果物の保持期間には管理者が設定した上限が適用されます
