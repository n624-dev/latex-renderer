## 確認する順序

1. **[稼働状況](/status/)を確認する**：サービス全体で障害やメンテナンスが発生していないか確認します。
2. **既存のジョブ状態を確認する**：すでに変換を実行した場合は、新しく作り直さずに同じジョブを開きます（Web では**履歴**、CLI では `n624-latex jobs get <jobId>`）。
3. **エラー診断とログを見る**：Web では結果画面の「診断」、CLI では `.render/errors.json` と詳細な `.render/compile.log` を確認します。

## 代表的な問題

### インストール・ログイン

- **`n624-latex`（または `latex-render`）が見つからない**
  新しいターミナルや PowerShell を開き直してください。改善しない場合は、Linux・macOS では [PATH の設定](/docs/client/#linux-macos)、Windows では[インストール手順](/docs/windows/#インストール)を確認します。
- **Web アプリにログインできない**
  管理者から案内されたログイン方式（パスワード / OIDC / Cloudflare Access）と登録済みアカウントを使っているか確認します。ChatGPT や Claude からの接続で止まる場合は[Remote MCP の接続確認](/docs/mcp/#chatgptなどの接続を確認する)へ進んでください。
- **CLI で `401` または `403` が返る**
  `n624-latex auth status` でキーの登録状態を確認します。管理者にキーが有効か、必要な権限（`render:create`・`render:read:own`）が付いているかを確認し、必要なら[キーを登録し直します](/docs/cli/#認証)。セルフホストの場合は[接続先 URL（`LATEX_RENDER_BASE_URL`）](/docs/cli/#接続先サーバー)も確認してください。

### アップロード・変換

- **ZIP 内に本文が見つからない**
  既定の本文はルート直下の `main.tex` です。親フォルダごと圧縮していないか確認するか、本文の相対パスを指定してください（[ZIP の作り方](/docs/projects/#構成)）。
- **ファイルサイズや拡張子が拒否された**
  不要な生成済みファイルや未対応ファイルを外すか、`.latexrenderignore` を設定し、[対応ファイルと制限](/docs/projects/#制限)を確認してください。
- **変換が待機中のまま、または途中で通信が切れた**
  サーバー側では処理が継続している場合があります。ジョブを作り直さず、同じ結果ページやジョブ ID を開き直してください。
- **パッケージ・フォントが見つからない、またはタイムアウトする**
  [レンダリング環境](/app/environment/)で利用可能な名前を検索してください。タイムアウトする場合は、ログの停止箇所付近にある複雑なマクロ、大きな画像、TikZ 図を確認します。

### 成果物の取得

- **PDF はあるが SVG がない**
  結果が**部分成功**であれば、先に PDF を保存してから **SVGだけ再試行**を実行します（[SVG 失敗時の対処](/docs/outputs/#pdf-はあるが-svg-が失敗した場合)）。
- **PNG プレビューが「準備中」のまま**
  同じページを少し待つか開き直します。確定済みの PDF は待たずに取得できます。
- **保存先が使用中、または `OUTPUT_BUSY` になる**
  出力先の PDF を開いているビューアを閉じるか、同じフォルダへ出力中の別プロセスが終わるのを待ってから再取得してください。
- **期限切れ・保存容量不足**
  保存期限が切れた場合は、保存済み改訂または手元のファイルから再変換します。個人の保存容量が上限に達した場合は不要な終了済みジョブを削除し、サーバー全体のディスク不足が表示された場合は管理者へ連絡してください。

## 問い合わせ

- **サーバー管理者への連絡**：発生時刻、どの操作で止まったか、表示されたエラーコード、分かればジョブ ID（`job_...`）を伝えます。
- **GitHub での公開不具合報告**：秘密情報や個人の文書を取り除いた最小限の再現手順を添えてください。**API キー、Cookie、元の文書、PDF、未編集の完全なログは絶対に公開しないでください。**
