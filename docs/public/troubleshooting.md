## 確認する順序

1. [稼働状況](/status/)を開き、発生している問題がサービス全体に及んでいるか確認します。
2. 変換を依頼済みなら、同じ変換結果を開きます。Web では**履歴**、CLI では `latex-render jobs get <jobId>` を使います。
3. エラーがある場合は、Web では結果画面の診断、CLI では `.render/errors.json` を確認します。LaTeX の詳細は `.render/compile.log` を確認します。

## 代表的な問題

### インストール・ログイン

- **`latex-render` が見つからない** — 新しいターミナルや PowerShell を開きます。Linux・macOS では [PATH の確認](/docs/client/#linux-macos)、Windows では[インストール手順](/docs/windows/#インストール)も確認します。
- **Web にログインできない** — 管理者が案内したログイン方式とアカウントを使います。AI からの接続で止まる場合は、[Remote MCP の接続確認](/docs/mcp/#chatgptなどの接続を確認する)へ進んでください。
- **CLI で 401 または 403 が返る** — `latex-render auth status` で資格情報を確認します。管理者にキーの有効性と `render:create`、`render:read:own` の権限を確認し、必要なら[キーを登録し直します](/docs/cli/#認証)。セルフホストの場合は[接続先](/docs/cli/#接続先サーバー)も確認してください。

### アップロード・変換

- **ZIP に本文が見つからない** — ZIP を開いて本文の相対パスを確認します。既定の本文はルートの `main.tex` です。[ZIP の作り方](/docs/projects/#構成)
- **サイズやファイル形式が拒否された** — 不要な生成済みファイルを外し、[対応ファイルと上限](/docs/projects/#制限)を確認します。
- **変換が待機中、または通信が切れた** — 同じ結果ページを開き直します。サーバーの処理は継続している場合があります。
- **パッケージやフォントが見つからない** — [レンダリング環境](/app/environment/)で使える名前を検索します。タイムアウトの場合は、ログに表示された場所のマクロ、画像、図を確認します。

### 成果物の取得

- **PDF はあるが SVG がない** — 結果が**部分成功**なら、PDF を取得して **SVGだけ再試行**を使います。[Web での再試行](/docs/web/#数式や-tikz-を-svg-で取得する)
- **PNG が準備中** — 同じページのプレビューを待つか、開き直します。PDF が利用可能なら先に取得できます。
- **保存先が使用中、または `OUTPUT_BUSY`** — PDF を開いているアプリを閉じるか、同じ出力先を使う処理の終了を待ってから再取得します。
- **期限切れ・容量不足** — 成果物の期限が切れた場合は、保存済みの改訂または手元のファイルから再変換します。自分の保存容量が上限に達した場合は不要な終了済みジョブを削除し、サーバー全体の空き容量不足は管理者へ連絡してください。

## 問い合わせ

管理者には、発生時刻、どの操作で止まったか、表示されたエラーコード、分かればジョブ ID を伝えます。公開の不具合報告には、秘密情報と文書を取り除いた再現手順を添えてください。API キー、Cookie、元の文書、PDF、完全なログは公開しないでください。
