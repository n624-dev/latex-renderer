- API キーが漏えいした場合は、直ちにサーバー管理者へ失効と再発行を依頼してください。
- ソフトウェアの脆弱性を発見した場合は、公開 Issue ではなく [GitHub の非公開脆弱性報告](https://github.com/n624-dev/latex-renderer/security/advisories/new)から報告してください。

## 資格情報

- API キーをコマンドライン引数（`ps` 等で見える箇所）、URL、Git リポジトリ、ログ、AI プロンプトに含めない。
- ローカル保存時は OS の保護機構（Windows は DPAPI、Linux / macOS は所有者のみ読める mode `0600` ファイル）を使う。
- ブラウザ用のパスワード・OIDC シークレット・セッション Cookie と、CLI / API 用のキー（`lrk_` / `lra_`）を相互に流用しない。

## プロジェクト

アップロードされる LaTeX ソースや添付ファイルはすべて「信頼できない入力」として扱われます。シンボリックリンク、シェルエスケープ、外部コマンド実行、コンテナ外へのネットワーク通信は無効化されています。サンドボックスや制限時間・ファイル上限を回避しようとしないでください。

## 公開領域と管理領域

公開ドキュメント・ダウンロード、認証済み Web（`/app/`・`/admin/`）、Renderer API は同一の正規 HTTPS Origin 上でパス分離されています。

- **ネットワーク境界**：Cloudflare プロファイルでは Tunnel / Workers、standalone プロファイルでは TLS リバースプロキシが唯一の入口となります。アプリケーションの各サービスはすべてループバックに bind し、Internal API・SQLite・manager ソケットは外部へ公開しません（認証領域は検索エンジンのインデックスからも除外されます）。
- **ブラウザ認証とセッション保護**：外部 IdP は `provider + issuer + subject` の完全一致でのみ本人を識別し、メールアドレスや表示名での自動名寄せは行いません。セッションはサーバー側で即時失効でき、状態変更リクエストには完全一致する `Origin` とセッション固有の CSRF トークンを要求します。パスワードは `scrypt` と root 所有 pepper で保護されますが、公開環境ではプロキシ側の接続数・レート制限およびホスティング側の DDoS 対策も併用してください。
- **Remote MCP の保護**：`/mcp`、OAuth トークンエンドポイント、discovery メタデータは公開到達可能ですが、ツールの実行には audience と scope を固定した短命 Bearer トークンが必須です。認可画面は `/app/` と共通のブラウザセッションを使って有効な既存ユーザーへ明示的に紐づけます。
  - 標準のツール応答（`content`）には、ワークフロー継続に必要な owner-scoped ID・状態・カーソル・制限付き診断のみを含め、ユーザー由来のパスや診断文は制御文字を除去し長さ・件数を制限した「未信頼データ」として返します。
  - OAuth トークン、API キー、チケット、生 base64、Source 全文、完全ログ、スタックトレース、Access subject、サーバー内部パスは標準 `content` や診断ログに含めません（完全な PDF やログの取得は所有者権限を再確認する Resource 読み取りに限定されます）。

## Local Setup Web UI

`n624-latex setup --gui`（旧版 `latex-render setup --gui`）は、ローカル端末上の `127.0.0.1` のランダムポートのみで待ち受け、外部インターフェースへは一切公開しません。

- CLI が開く URL のフラグメント（`#...`）に一回限りの bootstrap トークンを含め、ブラウザ側で直ちに履歴から消去して短命セッションへ交換します。
- 全操作 API に完全一致 `Origin`・Bearer セッション・別系統の CSRF トークンを要求し、CORS 無効・Host 検証・ループバック接続元検証・厳格な CSP・`frame-ancestors 'none'`・`no-store` を適用します。
- 入力された API キーは保存処理にのみ渡され、状態・診断・サンプル変換のレスポンスには含まれません。無操作 30 分、または起動から最大 2 時間で自動終了します。
