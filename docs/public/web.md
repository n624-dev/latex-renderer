## ブラウザでPDFへ変換

1. [Web アプリを開き](/app/)、管理者から案内された方法でログインします。
2. ファイルを選択するか、画面にドロップします。文書が 1 ファイルなら `.tex`、画像・参考文献・複数の TeX ファイルをまとめるなら `.zip` を選びます。
3. ZIP 内に複数の `.tex` があり、変換対象の選択欄が出た場合は、本文のファイルを選びます。
4. **PDFに変換**を押します。変換結果に PDF とページプレビューが表示されます。

別々の `.tex` を複数選ぶと、文書ごとに変換されます。1 つの文書が `\input` や画像を参照する場合は、参照先も含めて 1 つの ZIP にしてください。[対応ファイルと ZIP の構成](/docs/projects/)

## 数式や TikZ を SVG で取得する

変換前に**保存先・出力オプション**を開き、**数式とTikZをSVGでも出力**を選びます。PDF ができたら先に取得できます。結果に**部分成功**と表示された場合は、PDF を取得し、必要に応じて**SVGだけ再試行**を押してください。

PNG プレビューは最初のページから表示されます。続きのページを選ぶと、そのページを生成します。プレビューが準備中でも、利用可能な PDF は取得できます。

[PDF・PNG・SVG の保存方法](/docs/outputs/)

## 以前の文書や結果を開く

- **[履歴](/app/history/)**で変換の状態や成果物を開けます。ブラウザを閉じた後も、同じ結果ページに戻れます。
- **[プロジェクト](/app/projects/)**では、保存された文書や改訂を確認できます。以前の入力で変換するには、改訂を開き**もう一度変換**を押します。
- **[レンダリング環境](/app/environment/)**では、サーバーで使えるパッケージとフォントを検索できます。

## 公開・利用・管理機能の境界

Web アプリにはログインが必要です。自分の文書と結果は、ログイン後に履歴や結果ページから確認できます。管理画面は管理者と所有者が使います。[認証と文書の扱い](/docs/security/)

## 公開される情報

ログインできない場合は[稼働状況](/status/)と[問題解決ガイド](/docs/troubleshooting/)を確認できます。CLI は[ダウンロード](/downloads/)、アプリ連携の仕様は[HTTP API ガイド](/docs/api/)にあります。
