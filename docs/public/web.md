## ブラウザでPDFへ変換

1. [Web アプリ](/app/)を開き、管理者から案内された方法でログインします。
2. ファイルを選択するか、画面にドロップします。
   - 1 ファイルで完結する文書：`.tex` をそのまま選びます。
   - 画像・参考文献・複数の `.tex`（`\input` など）を含む文書：参照先も含めて 1 つの `.zip` にまとめて選びます（[対応ファイルと ZIP の構成](/docs/projects/)）。
   - 別々の `.tex` ファイルを複数選んだ場合は、それぞれ独立した文書として変換されます。
3. ZIP 内に複数の `.tex` があり、変換対象の選択欄が表示された場合は、本文（エントリポイント）のファイルを選びます。
4. **PDFに変換**を押します。完了すると、変換結果画面に PDF とページプレビューが表示されます。

## 数式や TikZ を SVG で取得する

1. 変換前に**保存先・出力オプション**を開き、**数式とTikZをSVGでも出力**にチェックを入れます。
2. PDF は完成した時点で先にダウンロードできます。
3. 結果に**部分成功**と表示された場合（PDF は成功し SVG のみ失敗した場合）は、先に PDF を保存し、必要に応じて**SVGだけ再試行**を押してください。

なお、PNG プレビューは最初に 1 ページ目だけが生成され、続きのページを開いたときに追加生成されます。プレビューの準備中でも、確定済みの PDF はすぐに取得できます。詳しくは[PDF・PNG・SVG を取得する](/docs/outputs/)を参照してください。

## 以前の文書や結果を開く

- **[履歴](/app/history/)**：変換の進行状態や成果物を確認できます。ブラウザを閉じた後でも同じ結果ページを開き直せます。
- **[プロジェクト](/app/projects/)**：保存された文書や改訂（リビジョン）を確認できます。過去の入力内容で再実行したいときは、対象の改訂を開いて**もう一度変換**を押します。
- **[レンダリング環境](/app/environment/)**：サーバーで利用可能な LaTeX パッケージやフォントを検索できます。

## 公開される情報

- **ログインが必要な画面**：Web アプリ（`/app/`）の利用にはログインが必要です。自分の文書と変換結果は、ログイン後に履歴や結果ページから確認できます。管理画面（`/admin/`）は管理者と所有者のみ利用できます（[アカウント・文書の安全な扱い](/docs/security/)）。
- **ログイン不要で公開される情報**：ログインできない場合は[稼働状況](/status/)や[問題解決ガイド](/docs/troubleshooting/)を確認してください。CLI の入手先は[ダウンロード](/downloads/)、システム連携の仕様は[公開API](/docs/api/)にあります。
